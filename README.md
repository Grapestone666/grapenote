# 📌 记事贴 — Windows 11 风格桌面任务管理小组件

一款轻量级 Electron 桌面应用，以 Windows 11 Fluent Design 风格呈现，像便利贴一样常驻桌面，帮助你管理日常任务和跟踪进度。

## 功能特性

- **常驻桌面**：无边框置顶窗口，像便利贴一样钉在桌面
- **任务管理**：添加、编辑、完成、删除任务
- **分类筛选**：按工作/生活/学习等分类查看，支持自定义分类
- **截止日期**：自动标识过期任务，过期任务置顶并红色警告
- **循环任务**：支持每周/每月循环，完成后自动计算下一次截止日期
- **系统托盘**：关闭窗口最小化到托盘，不打扰工作流
- **数据导出**：一键导出已完成任务记录为 CSV 文件
- **窗口记忆**：自动保存窗口位置和大小

## 环境要求

- **Node.js** 18.0 或更高版本
- **Windows 10/11**（推荐 Windows 11 以获得亚克力毛玻璃效果）

## 安装与运行

```bash
# 1. 克隆或进入项目目录
cd sticky-tasks

# 2. 安装依赖
npm install

# 3. 启动应用
npm start
```

## 打包为 .exe

```bash
# 安装 electron-builder（已在 devDependencies 中）
npm run build
```

打包产物位于 `dist/` 目录下。

## 快捷操作

| 操作 | 说明 |
|------|------|
| 输入框 + 回车 | 快速添加任务（使用当前筛选分类） |
| 点击 ▾ 按钮 | 展开详细设置（备注、日期、循环等） |
| 点击任务 | 打开编辑弹窗 |
| 右键任务 | 弹出编辑/删除菜单 |
| 右键自定义分类 | 删除该分类 |
| 📌 按钮 | 切换窗口置顶 |
| ✕ 按钮 | 最小化到系统托盘 |
| 双击托盘图标 | 恢复窗口显示 |

## 数据存储

任务数据保存在系统用户数据目录下的 `tasks-data.json` 文件中：

```
Windows: %APPDATA%/sticky-tasks/tasks-data.json
```
